## Project Structure

The portfolio is intended to use these files:

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── page-audit.md
└── README.md
```

- `index.html` — Semantic structure and page content.
- `style.css` — Layout, responsive styling, and color theme.
- `script.js` — Mobile navigation, current copyright year, and other small interactions.
- `page-audit.md` — Quality-assurance checklist and verification status.
- `README.md` — Project overview and setup instructions.

## Getting Started

1. Open the `portfolio` folder in Cursor or Visual Studio Code.
2. Make sure `index.html`, `style.css`, and `script.js` are present.
3. Open `index.html` directly in a browser, or use the **Live Server** extension in Visual Studio Code for local preview.
4. Replace clearly marked placeholders with your actual contact details, social links, showreel, and project media.
5. Review the site on mobile, tablet, and desktop before publishing.

## Customizing the Color Theme

Define the theme in `style.css` using reusable CSS variables:

```css
:root {
  --ice-silver: #DDE3E8;
  --deep-aubergine: #3A0F34;
  --marigold: #EAAA00;
}
```

Use Deep Aubergine for strong dark sections, Ice Silver for light backgrounds, and Marigold for restrained accents and calls to action. Check text contrast for accessibility.

## Content Guidelines

- Use only genuine projects, footage, showreels, client details, and achievements.
- Do not present stock footage or sample content as your own work.
- Do not invent work history, years of experience, certifications, or client testimonials.
- Keep unavailable links and media clearly marked as placeholders until supplied.
- Verify that all navigation links point to valid section IDs.
- Respect reduced-motion preferences and provide visible keyboard focus states.

## Quality Checks

Before publishing, verify:

- All required files exist and are correctly linked.
- Navigation and mobile menu work.
- Project and social links point to genuine destinations.
- Video embeds and media assets load correctly.
- Layout works across desktop, tablet, and mobile.
- Keyboard navigation, focus indicators, and text contrast are usable.
- `page-audit.md` accurately records completed and pending checks.

You can validate the HTML with the [Nu HTML Checker](https://validator.w3.org/nu/).

## Deployment

This is a static website and can be hosted on a static hosting platform such as Vercel or GitHub Pages.

For Vercel, import the repository and deploy it as a static site. For GitHub Pages, push the website files to a repository and configure Pages to publish from the selected branch or folder.
